Zeros — Design System

The complete token reference for the Zeros Mac app: every primitive in styles/zeros-tokens.css, how each one is used, the usage rules & anti-patterns, and a live component library (mirroring src/zeros/ui/primitives/). Two themes ship: Zeros Shade (dark — muted warm-gray, HSL) and Light (warm off-whites, added 2026-07-11) — flip this page with the toggle (top right), which swaps data-theme="light" on <html> exactly like the app's appearance store. Rendered on the real app canvas (--bg1). For semantic color applied to real UI, see color-palette-preview.html.

Foregrounds text + icons ONLY — never borders

Three-and-a-bit tiers. The default is fg2; reach for fg1 only when text/icon should pop (selected, highlighted, focal output). --fg3 is the faint-metadata tier; --muted-fg is placeholders / empty states.

Usage rules surface map · recipes · anti-patterns

Full reference: styles/zeros-foundation.md. The essentials:

Surface & foreground map

Depth ladder. Canvas bg-bg1 → composer bg-bg2 → popover/dropdown/card bg-bg3. Dialog content is the exception (bg-bg1). Workspace sidebar (col 1) bg-sidebar-bg.
Hover is surface-scoped. bg1 → bg-bg1-hover, bg2 → bg-bg2-hover, bg3 → bg-bg3-hover, sidebar → bg-sidebar-bg-hover. Never jump two tiers.
Foregrounds. Default text-fg2; highlighted/selected/focal text-fg1; placeholder text-muted-fg.
Selected = the sticky hover. A selected row uses that surface's hover token, just persistently.
Borders. Default border-border1; components border-border3; highlighted state border-border4.
Focus. Most controls get a ring-[3px] ring-highlighted-bright/50; inputs & selects swap the border to border-highlighted-bright with no ring.

Anti-patterns (most likely to slip)

✗ Never use a foreground token as a border — --fg* are text + icons only.
✗ Never use a background token as text, or a border token for fills/text. Each family stays in its lane.
✗ One primary button per visible screen. A second focal CTA → demote to secondary or ghost.
✗ --highlighted-bright is the focus/border accent, not a button fill.
✗ No inline hex / rgb / oklch / hsl in components — if a value isn't a token, add it to zeros-tokens.css first.
✗ No bare Tailwind color classes (bg-white, text-gray-500) — only Zeros primitive utilities.
✗ Never reference a numeric ramp step (text-red-500, var(--blue-600)) in component code — snap to the anchor. check:ui enforces this.

Typography · spacing · motion

Type (strict 12/14 chrome). Titles text-sm font-medium, body text-sm, captions/badges text-xs, counts text-xs tabular-nums. Fonts: Geist Variable / Geist Mono Variable.
Spacing (4px grid). p-2 / p-3 / p-4 / p-6. No p-3.5, no space-y-5.
Radius (fixed 3-step). rounded-sm 4 (ALL buttons · pills · badges · kbd · menu items · inputs · user msgs) · rounded-md 6 (tabs · model pill · sidebar/settings nav rows · small cards · tooltips) · rounded-lg 8 (composer · dialogs · popovers · cards) · rounded-full circles only. Nothing else compiles.
Motion. Hover 120ms ease-out · popover 180ms · dialog 240ms. Only animate color/bg/border/opacity/shadow/transform — never transition:all.

Buttons

secondary is the default variant — the everyday button. Primary (variant="default") bg-primary-button-bg / text-primary-button-fg / hover:bg-primary-button-hover — one per screen · Secondary bg-bg2 + border-border2 + text-fg1, hover:bg-bg2-hover + border-border3 (restyled 2026-07-12) · Ghost transparent + text-fg2, hover:bg-bg3 + text-fg1 · Destructive bg-red-secondary + text-red-secondary-fg · Destructive-secondary same neutral surface as Secondary, text-red-primary. variant="outline" is retired — use Secondary.
