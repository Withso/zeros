05 · Design-system contract

Exact type, spacing, controls, and behavior.

The task dock is a chat primitive, not a dashboard card. Density stays inside the existing IDE scale; status color is reserved for small dots and badges rather than large tinted surfaces.

Visual metrics

Page heading
20/24 · weight 600
Section heading
18/24 or panel 15/20 · weight 600
Chat body
13/20 · weight 400
Controls
12/16 · weight 500
Metadata
11/16; micro labels 10/14 mono
Spacing
4px grid · 8 row gap · 12 card inset · 28 chat gutter
Controls
24 icon/pill · 28 button · 32 input/send
Radii
4 controls · 6 rows · 8 cards/docks
Surfaces
bg1 canvas · bg2 composer · bg1-hover rows · tonal borders

Task-dock behavior

One task
Collapsed summary by default; one click reveals the row.
Two to four
Expanded on first appearance; remember the user’s collapse per chat.
Overflow
Show four rows, then “N more · View all” in a task detail surface.
Attention
Expand once for a failure or input request and badge the chat tab.
Completion
Append the transcript record before removing the live row.
Refresh
Keep the last confirmed exact-chat snapshot while revalidating.
Hidden chat
Rows remain inert; timers and polling gate on active visibility.
No tasks
Render nothing—never leave an empty task header above the composer.

Permission behavior

Placement
Permission card replaces the composer; task summary remains above it.
Attribution
Name the requesting helper, model, command/tool, and requested boundary.
One-time
The sole focal action uses Primary. Sticky choices stay outlined.
Keyboard
Enter once · ⌘Enter chat scope · ⇧⌘Enter project · Esc deny.
Focus
Focus enters the card, remains trapped, and returns to the draft.
Resolution
Leave Allowed/Blocked plus actor and scope beside the tool record.

Content rules

Task name
Human label first; raw command or wait condition is secondary mono text.
Status
Running/waiting/done/failed plus elapsed time; never a spinner alone.
Agents
Name + model + effort + last meaningful heartbeat.
Terminals
Use the shared name + elapsed + Stop row; no provider, CPU, or memory chrome.
Schedules
One-shot next checks join the task card; recurring schedules (008) remain skipped.
Failures
One-line cause in the record; full output stays one click away.

Shared row anatomy

Tool / agent row
36px minimum · 24px glyph · label + secondary detail · status/action endcap.
Activity line
24px minimum · 11px metadata · visible verb, state, and elapsed time.
Status badge
18px minimum · 10px mono · color reserved for the small state surface.
Progress
4px tonal track plus numeric count; never use a bar without text.
Message kinds
Commentary muted · final primary · system and scheduled records neutral.
Media
Bounded preview, type icon, filename, dimensions/duration, and Open.

State and performance behavior

Ownership
Runtime state is exact-chat keyed; provider settings are provider keyed.
Refresh
Retain the last confirmed exact-key snapshot during revalidation.
Streaming
Append deltas and structurally share settled rows; never replace the full turn.
Attention
Badge only input/failure; ordinary progress remains quiet inside the chat.
Hidden views
Retained chats are inert and gate timers, polling, shortcuts, and focus.
Cold load
No fade or skeleton to hide a waterfall; delayed busy UI only for a real cold read.
