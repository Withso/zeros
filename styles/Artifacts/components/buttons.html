Buttons

Every button the Zeros app ships, straight from the primitive in apps/desktop/src/renderer/shared/ui/primitives/button.tsx. Five variants (Primary, Secondary, Ghost, Destructive, Destructive-secondary — the old outline alias is retired; use Secondary) across a shared 3-step height scale (24 / 28 / 32px, for text and icon-only alike), with and without icons, width options, split buttons, and every interaction state. Flip dark / light with the toggle (top-right). Base for all: rounded-sm 4px, px-2.5 10px, gap-2 8px, text-sm 13px medium, icon size-4 16px.

Sizes height only — width always follows content

Three text heights. default (28px) is the everyday size; sm (24px) for dense toolbars and inline rows; lg (32px) for roomy dialog footers and primary CTAs. Only the height (and, for sm, the font size) changes — padding, radius, and gap are shared.

With & without icon leading, trailing, both — 16px icon, 8px gap

Icons sit inside the same flex row at size-4 (16px) with the shared gap-2 (8px). Leading icon is the common case (an action verb + its glyph); a trailing chevron/arrow signals "opens more" or "moves forward."

Icon-only square buttons — same 3-step scale as text sizes

Square buttons that drop text and padding. The squares mirror the text heights so mixed rows line up: icon-sm 24×24, icon 28×28, icon-lg 32×32. Always pair with a tooltip or aria-label since there's no visible text.

Width fit (default) · fixed · full-block

Buttons are w-fit by default — width follows the content. Add w-full to stretch across a container (dialog footers, empty-state CTAs, mobile sheets), or set an explicit width to line up a column of equal-width actions.

Split buttons primary action + attached chevron menu

A composed pattern (not a primitive variant): the main action welded to a chevron that opens related choices. Two <Button>s share one silhouette — a 1px seam splits them, outer corners keep the 4px radius, inner corners square off, and the chevron half is a square icon button.

States default · hover · focus · disabled · loading

Focus shows a 3px highlighted-bright/50 ring plus a solid accent border. Disabled drops to 50% opacity and blocks pointer events. Loading swaps the leading glyph for a spinner and holds the button disabled so the action can't fire twice.
