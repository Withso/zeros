Popups & Overlays

Every UI in the Zeros Mac app that opens in a floating layer — modal dialogs on a dimmed scrim, the create-workspace composer, the command & keyboard-shortcut palettes, the image lightbox, and every anchored dropdown, context menu, select, popover and hover card. All are built from the Radix / cmdk primitives in apps/desktop/src/renderer/shared/ui/primitives/. Two layers make an overlay: a full-screen scrim (dialogs only) and a floating panel. Demos are static reproductions of the shipped components — flip dark / light with the toggle (top-right).

Foundations the two-layer model every overlay shares

An overlay is a scrim (a full-screen veil that traps focus) plus a floating panel. Only modal dialogs (and, in theory, sheets) draw a scrim; anchored overlays — dropdown, context menu, select, popover, hover card — have no scrim and simply float beside their trigger. Everything is z-50, rounded-lg (8px), and lifts on --shadow-dropdown.

Modal dialog the Dialog primitive — anatomy

A centered panel on a scrim. bg-bg1 + 1px border1 + rounded-lg + --shadow-dropdown, p-6 (24px), max-w-lg (512px), internal grid gap-4. Header (title + optional description), a body, and a right-aligned footer. An optional close × sits top-right. Dialogs are non-dismissable by default — clicking the scrim will not close them (so an accidental click can't discard a half-typed form); callers opt in with dismissable.

Confirmation dialogs destructive — a Dialog + a red button

There is no AlertDialog primitive. A destructive confirmation is an ordinary Dialog whose confirm button is variant="destructive" (solid red). No ×, focus defaults to Cancel, and it can’t be dismissed mid-action. Many confirm on ⌘↵.

Keyboard shortcuts ShortcutsPalette — the glass one

The only overlay with a frosted-glass panel — the base recipe for overlays. A light bg-scrim/30 veil, then a bg-bg2/30 · backdrop-blur-[28px] · saturate-[1.2] panel dead-centered on both axes at a fixed height (660px wide, h-[min(72vh,344px)] — sized to exactly eight shortcut rows, the same on every tab / search state, responsive to small windows via the vh term; the list scrolls inside). Search box, category tabs (browse mode — the app-wide tab pill, no border, the translucent --selected-glass fill when active), and view-only rows — each a 14px label + optional category tag + borderless Kbd chips, both chips on the same --selected-glass wash. Open with ⌘/ (toggles; Esc / click-away closes).

Not overlays look adjacent, but don’t float on a layer

A few things read like popups but aren’t — catalogued so nobody re-implements them as one.

ThingWhat it actually is
Sheet / DrawerThe sheet.tsx primitive exists (edge-anchored, bg-bg1, open 500ms) but its only consumer — the shadcn Sidebar mobile sheet — is never mounted. There are no active sheets/drawers in the app.
AlertAn inline callout box (alert.tsx) — no scrim, no portal, no shadow. Default = bg-bg1; destructive = 50% red border + red text. Lives in the page flow.
ToastUpdate notifications (“New update available” / “You’re up to date!”) are toasts — a neutral bg-bg1 card, only the status icon carries color.
Permission requestAn inline card in the chat transcript (permission-card.tsx), not a modal.
Effort / Permission / Fast pillsComposer pills that cycle on click (each advances the value, tooltip names it) — they open no panel. Only the model pill is an overlay.
Full-screen viewsLogin, auth gate, “Worktree missing”, and the no-projects welcome paint an opaque bg-bg1 over inset-0 — they replace the app, they don’t float over a dimmed scrim.

Rules
✓ Scrim only on modals. Dialogs (and sheets) get a full-screen bg-scrim. Anchored overlays — menu, popover, select, hover card — never do; they float beside the trigger.
✓ Mind the surface. Dialog & sheet panels are bg-bg1; the create composer & hover card are bg-bg2; every menu / popover / select / command panel is bg-bg3. All rounded-lg, all --shadow-dropdown.
✗ Don’t add backdrop blur. Only two surfaces blur app-wide: the Shortcuts palette panel and the Image lightbox scrim. Every other scrim is a flat wash.
✗ Don’t reach for an AlertDialog. There isn’t one — a destructive confirm is a Dialog + a variant="destructive" button, with focus defaulted to Cancel.
✓ Guard work-holding dialogs. Dialogs are non-dismissable by default — a stray scrim click won’t discard a half-typed form. Opt in to click-away (dismissable) only for pickers/palettes.
✗ ⌘K is not a command palette. It focuses the message box. The one centered command palette is the workspace/directory picker; other action lists are anchored popovers.
✓ Use Kbd for shortcut chips (border1, 11px, fg2) and the inline tracking-widest opacity-60 variant only where a menu row needs a lighter hint.
✓ Trust overlay-focus. Closing an anchored overlay with the mouse drops the focus ring; closing with the keyboard restores it. Don’t hand-manage trigger focus.
