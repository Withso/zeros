Tooltip

The single tooltip for the Zeros Mac app — a glass chip on --bg2 with a backdrop blur. It sits above the trigger, centered, and flips below when it hits the top edge. There are no native title= system tooltips anywhere; any library component that ships its own tooltip is overridden with this one. Backed by src/zeros/ui/primitives/tooltip.tsx (Radix). Hover the demos — they're live.

Live hover / focus the triggers

Default placement is top & centered on the trigger. The chip is translucent --bg2 (40%) + backdrop-blur(10px) & saturate, text --fg1 at 12px, a 50% --border2 hairline, and the --shadow-dropdown lift. An optional keyboard shortcut renders muted (--fg2) after the label.

Responsive collision-aware — flips below at the top edge

When there isn't room above (a control flush against the top of a panel / the window), the tooltip flips below the trigger, staying centered. Near a side edge it nudges inward so it never clips. Radix computes this automatically; below is the top-edge case (as in the ⌘⌥B toolbar).

Usage

One component, one call. The child is the trigger (a native element or any ref-forwarding component). Empty label renders the trigger bare — no empty chip.

// the everyday case — replaces every native title=""
<Tooltip label="New terminal">
  <Button variant="ghost" size="icon"><Plus /></Button>
</Tooltip>

// with a keyboard shortcut
<Tooltip label="Toggle right sidebar" shortcut="⌘⌥B">
  <button aria-label="Toggle right sidebar">…</button>
</Tooltip>

// side / align overridable when a spot needs it (default top-center)
<Tooltip label="Details" side="right">{trigger}</Tooltip>
Rules
✗ No native title="" anywhere — it renders an unstyled OS chip, ignores the theme, and can't be positioned. Replace with <Tooltip>.
✗ No second tooltip style. If a library component ships its own tooltip, disable it and wrap the trigger in ours.
✗ Don't hand-roll a hover popover for a label — that's what this is.
✓ Keep aria-label on icon-only triggers (the tooltip is a visual hint, not an accessible name).
✓ One TooltipProvider at the app root owns the delay; don't nest more.
✓ Label names the action in ≤ ~5 words (“Create PR”, “Adjust effort level”, “Open in…”). Put the key hint in shortcut.
✗ No sentences, no “click to…”, no parentheticals, no restating visible text (a workspace row’s own name needs no tooltip). Long help text belongs in a Popover / HoverCard.
✓ The only long labels are identity reveals — a truncated file path / name shown in full. These wrap at max-w-xs.
