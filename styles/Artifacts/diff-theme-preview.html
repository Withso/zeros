Diff theming — plan & preview

How @pierre/diffs will look once wired to the Zeros palette. We set three base overrides; @pierre derives every tint (row background, the changed-word emphasis, the edge bar, the line numbers) from them — so the whole diff stays consistent. Syntax colors keep coming from the Shiki code theme; context/gutter stay neutral. The mockup below uses the same color-mix formulas @pierre uses, so it's a true preview.

Tokens — what we set & what each controls

@pierre override we setZeros valueControls (derived)
--diffs-addition-color-overridevar(--green-primary)added line: row wash · changed-word emphasis · left edge bar · line number
--diffs-deletion-color-overridevar(--red-primary)removed line: row wash · changed-word emphasis · edge bar · line number
--diffs-modified-color-overridevar(--blue-primary) (or neutral — see below)the “modified” / selected-line accent — replaces @pierre's navy #69b1ff

Plan (once you approve)

  1. In src/zeros/appearance/diff-theme.ts → DIFF_SHADOW_CSS, add the 3 --diffs-*-color-override vars (green/red + chosen modified). They inherit into the diff shadow root and win because @pierre leaves the -override slots unset.
  2. @pierre derives row wash + word emphasis + edge bars + line numbers from them — no per-tint work needed.
  3. Optional fine-tune: if the wash reads too strong/soft vs. these mocks, set --diffs-bg-addition-override / --diffs-bg-addition-emphasis-override (and deletion) explicitly.
  4. Applies everywhere the renderer is used: Changes tab, Review tab, file-tab diff mode, chat EditCards.
