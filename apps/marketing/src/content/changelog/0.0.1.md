Zeros is now in **public beta**. It's a Mac workspace where parallel AI agents
design, build, and ship across isolated git worktrees — you watch them work,
review every change, then merge.

## What's in the first build

- **Parallel sessions.** Run Codex, Claude, and Cursor side by side. Every
  session gets its own isolated git worktree and branch, so agents never step
  on each other's files.
- **Design canvas.** An infinite canvas with draggable frames lives next to the
  agent loop. Hand a frame to an agent as context and preview the UI as it's
  written.
- **Review & merge.** See exactly what each session changed, file by file.
  Approve, request changes, or merge straight to `main` without leaving the
  workspace.
- **Bring your own agents.** Your models, your keys, your machine — nothing runs
  in our cloud.

## Notes

- Apple Silicon only for now (Intel support is planned).
