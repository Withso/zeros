How to read a sheet

  • Each frame is one component: name, purpose and source file, then variants × states, specs as tokens, and notes where it disagrees with the rest of the system.
  • Hover and Focus specimens apply the component's own hover and focus-visible classes, so they show the real recipe.
  • Pills and the final Audit frame compare components side by side to settle radius, height and type choices.
  • Not on this page yet: the animated loaders (Orbit, Puzzle, Glass), chat elements (code block, reasoning) and the Design inspector's own controls.
