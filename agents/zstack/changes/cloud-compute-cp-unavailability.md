# Keep funded compute through temporary database unavailability

A generic reconciliation catch converted connection loss and pool/statement
failure into a safety stop, even with prepaid provider time remaining. Failed
re-observation also collapsed unknown proof into revoked authority. Exhausted
transaction retries retained no useful closed error classification.

Retain real PostgreSQL connection termination both before and after COMMIT,
real statement and pool timeouts, and exhausted rollback retries. Re-observe
canonical reservation/meter state before domain writes; no provider I/O may
live inside a DB retry and ambiguous COMMIT is never replay permission. Unknown
proof can defer only within an already confirmed finite deadline. Keep negative
revocation/corruption, replaced-generation, earlier-deadline and clock-failure
controls, and add closed compute sites without logging raw exceptions.

Local workspace lifecycle remains independent of these CP cloud services. The
historical generic incident does not identify its underlying exception; tests
prove the failure-handling defect without inventing that missing evidence.
