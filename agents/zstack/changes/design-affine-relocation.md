# Design affine relocation and failed-write recovery

Canvas movement mixed screen deltas, world bounds and local CSS lengths; subtree extraction also lost inherited appearance, while a failed second file write could leave the first file changed.

Keep the world grab anchor, invert the complete parent affine map, and retain margins in bounded geometry snapshots. Admit only source contexts the relocation planner can preserve, recheck stylesheet identity at commit, and persist an inverse recovery journal before rolling back a failed multi-file edit.

Encoded in the protocol layout-geometry/relocation suites, renderer movement/drop tests, and engine relocation/relocation-geometry suites. The browser-backed extraction regression compares all four corners, not only an axis-aligned rectangle; the disk-failure regression reads the original source before any recovery-capable read.

The first renderer check is not commit authority: a stylesheet can change while journal preparation awaits I/O. Carry measured identity into the existing Foundation repository commit and validate it again immediately before journal admission. The relocation suite holds that boundary and asserts no authored bytes change. Preflight both escaped forward and inverse lifecycle journals before even updating `.gitignore`; retain the existing journal, history and snapshot bounds.

Canonical references are not a mutation list. Consume the shared ancestry projection, keep explicitly selected descendants, and refuse cross-scene movement rather than applying independent partial writes. Real-pointer fixtures cover a free affine child's release, different reflected/scaled parents in one transaction, current-camera scene movement, and world-space 1/8 nudges.

Keep an authored free layer distinct from a flow child temporarily dragged out of its layout. The native `--zeros-layout-origin-flow` inline hint preserves flow reentry; read only the node's own hint and never capture it as inherited appearance. Existing flow/guide-cancellation smoke and runtime context tests guard this compatibility seam.

A finished keyboard gesture owns its captured targets while Foundation loads; a later selection must not discard that completed edit. Validate membership when the key is released, while retaining page, lifetime, theme, runtime and measured-source fences through admission. Held gestures and queued follow-ups still retire on selection changes. The existing cold-Foundation smoke proves the original pair commits once after selecting a different layer.

Consecutive scene drags may begin from a local preview whose save has not acknowledged. Chain only that known predecessor's receipt, not an arbitrary newer source, and use its confirmed source and geometry for the next guarded write. An independent scene move must not ask a retiring HTML runtime for relocation measurements when no receiving frame exists. A held-acknowledgement browser regression checks both the second move and its cancellation; the full layout-gesture smoke retains its back-to-back position assertion.

A visible structural preview can also precede admission to the existing workspace mutation queue. Retain that completed gesture's save promise, then drain the existing queue and measure fresh DOM geometry only for a confirmed local generation with unchanged scene geometry. Do not retry or rebase a measured write. Cancellation before the next gesture has touched the native DOM must not cancel the preceding gesture's move preview; restore only the new overlay from current measurements. Held-reorder browser tests and Local/cloud lineage-refusal tests retain these boundaries.

A sparse DOM fixture hid a real producer/consumer mismatch: inherited appearance plus normalization exceeded the existing 64-style bound. Admit the complete payload, including custom properties, before preview; compact redundant resets without dropping inherited table appearance. Publish compact inline overrides after older longhands, and retain every affected longhand before a shorthand preview changes it. Real runtime-to-preview-to-writer, cancellation, teardown and native undo/redo regressions cover the same payload.

An earlier file-wide preflight is not publication authority. Recheck each exact before-image immediately before its atomic replacement; an external third value must survive with the guarded inverse journal, not be overwritten. Carry cached and fresh stylesheet/font/asset byte fingerprints across every awaited final frame read and revalidate the whole dependency set at synchronous journal publication. Imported styles outside the editable Foundation snapshot need the same guard for semantic edits. Retain every canonical-path policy when consumers share a dependency; a less restrictive later read cannot replace the first reader's authority. Retained tests move the external write across the destination identity read and temporary-journal preparation; these guarantees do not imply filesystem-wide ACID against arbitrary native writers.

A released scene save needs a surface/page lifetime, not the next pointer gesture's selection token. Preserve the completed predecessor through cold Foundation admission and cancellation of its successor. Numeric runtime revision equality does not establish physical runtime identity: require the captured connection to remain active. Relative movement must also update a finite end offset with the opposite delta so RTL's governing right offset actually moves. Cold-scene, real reconnect, owner/page ABA and painted RTL/LTR single/group 1/8-pixel controls are retained in the refinement smoke suite.

An advisory HTML overlay and a stylesheet preview can disagree with the saved source even while its version is unchanged. Warm saved editing on actual input intent, hide HTML before admission, drain and restore every applied stylesheet, and refresh canonical geometry before accepting input. Bind preparation to its semantic owner, source and physical connection; a late acknowledgement cannot reopen a retired session. Keep passive drafts intact, and drain completed gesture saves before returning to advisory viewing. The public browser fixture holds CSS acknowledgements across source, same-version runtime, directory, page, rendered workspace and visibility replacement, then proves a fresh one-pixel edit. Its source-save and owner-switch controls must publish matching Foundation generations and exact-path snapshots, not bypass those production guards.

Check the painted surface, not only the DOM beneath it: a retained zoom tile can cover a restored runtime under that same source identity. After advisory styles have painted, direct editing uses live pixels instead of that optional tile; passive viewing and normal no-draft zoom rendering remain available. Hold the replacement capture to prove an old tile cannot masquerade as authoritative saved pixels.

Tree selection and disclosure are not editing intent. Preserve passive drafts while choosing canonical references or navigating the tree; enter the saved-pixel fence for canvas interaction, property controls and mutating shortcuts. The unchanged selection-reference smoke and the saved-editing HTML/CSS regression cover this boundary without weakening either contract.

Mounting a frame beneath a stationary pointer is not input intent either. Warm restoration on real pointer movement or focus, not layout-generated pointer-over events. A parked-pointer remount regression and the unchanged recovery-to-draft scenario keep passive viewing available after native frame recovery.
