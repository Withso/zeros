# Exact owner discard recovery

A retired failed save still blocked an owner-approved recovery and release health.
Provider-loss evidence retires allocation authority; it does not settle final-save
custody or authorize discarding unsaved work. Add a separate immutable owner
receipt bound to the exact original capture, restart, checkpoint and replacement
Computer. Preserve final-save proof as false and keep every other workspace gated.

Test deployed health predicates as well as new readers. A reader-only exclusion
cannot unblock the release that must deploy it. The terminal discarded state and
no-retry timestamp keep the original failure and custody while surviving N-1
health and worker writes. Exercise the actual CLI under a temporary login that
selects the stable table owner; do not assume the login owns the tables.

Encoded in manage-cloud-owner-checkpoint-recovery.integration.test.ts, the private
input tests, the exact 0172 migration tests, and the operator runbook. No change to
Local workspaces or ordinary Stop/Restart policy.
