A cold base refused the fixed `/usr` edge because its mount ID differed from
the root mount. A separate earlier template observation did not establish that
lineage's topology. Accept only a positively native, root-owned fixed anchor;
never infer provider provenance from device equality or a mount-source name.

Ordinary mount IDs may be recycled after the final reference closes. Retain
bounded original anchor descriptors through retry and diagnostic I/O, unwind
per-pass descriptors, and repeat the complete named/table/ACL/policy proof.
An open detached descriptor is not current named attachment. Test replacement
of the same inode/generation tokens, release on every exit, actual command
signals and original deadlines. The optional-systemd mount suite and seeded
anchor-reference eval retain these controls; no live native qualification is
claimed by a rootless mount model.

Permission-sensitive fixtures drop all capabilities. When invoking the actual
command entry point, restore its signal handlers and umask before the next
test; otherwise a private-mode setting can contaminate a later native test.
