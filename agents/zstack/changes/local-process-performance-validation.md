## Local process performance validation

Inherited credential shims could resolve another shim as the real executable,
then re-execute themselves indefinitely. Resolver tests now cover nested
brokers, directory and executable symlinks, copied shims, dead brokers and
normal Local/cloud invocation. Validate both executable selection and script
re-entry; a resolver guard alone cannot protect an already-issued shell.

Independent Git badge and status reads repeated the same work. Native spawn
budgets now cover a four-workspace refresh, an idle minute and a turn with
edits. Sharing must retain exact comparison keys and a bounded joining window.
Foreground consumers promote a queued shared observation; a background
concurrency limit must not delay the selected workspace behind tab fan-out.

Periodic Local dropbox scans and focus-triggered updater checks kept doing
work without a changed input. Fake-clock tests count scans, active timers,
consumed receipts and native checks, including failed watches and slow checks.
Drain each observed directory listing once: unconditionally rescanning on
completion can turn a failed claim into a busy loop. Keep sparse built-in
memory history for leak diagnosis, coalesced with requested samples; this
history must never launch a process-table or system-information subprocess.

An optional event-loop observer passed its own suites but broke engine
composition fixtures whose reporter omitted the new method. Exercise the
whole engine composition and Electron test directories for cross-cutting
diagnostics changes, and keep optional observations optional at their caller.
The retained workspace mutation and review transport tests reproduce this
failure. A Linux SSH test host also needs `/usr/bin/nc`; install that host
prerequisite rather than changing the runtime's cloud transport behavior.

The matching replay cases cover shim resolution, shared Git process budgets,
idle dropbox scans and automatic update cadence. Provider delivery numbers are
explicitly synthetic replays; native macOS CPU, RSS and lifecycle checks remain
separate evidence and cannot be inferred from a Linux fixture.
