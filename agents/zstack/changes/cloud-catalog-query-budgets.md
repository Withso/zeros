# Count query round trips as well as transactions

A transaction budget can pass while its sequential statements still dominate
network time. Measure the application query port through the real HTTP path,
including transaction setup and completion, and compare empty, single-row and
multi-row requests before calling a latency improvement complete.

Catalog authority may share a request-local connection fingerprint per owner
scope. Each workspace still needs its own live proof and every original source;
repeat the batch fence after reading metadata. Stopped workspaces retain fresh
admission, and a failure keeps recovery metadata and its monotonic version.
